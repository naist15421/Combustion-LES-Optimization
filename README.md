# 3D LES Combustion Simulation & Parameter Optimization

ES提出用リポジトリです。
燃焼器内の乱流予混合火炎を解析するための3次元LES（Large Eddy Simulation）コードと、シミュレーション定数を実験値に適合させるためのベイズ最適化スクリプトです。

## 概要 (Overview)
本プロジェクトは以下の3つの主要なコードで構成されています。

1. **`les_combustion_solver.c`**
   - 3次元LESによるメタン-空気予混合火炎の燃焼シミュレーションコード。
   - OpenMPを用いた並列計算を実装。
   - G方程式（レベルセット法）を用いた火炎面追跡と、WENO5/MUSCLスキームなどの高次精度風上差分を実装。
   - 合成渦法（SEM）による流入乱流の生成。

2. **`bayesian_optimizer.py`**
   - Gaussian Process（ガウス過程回帰）を用いたベイズ最適化スクリプト（`scikit-learn`を使用）。
   - LESコードが出力したレイノルズ応力のプロファイルを読み込み、実験値の近似曲線との誤差（スコア）を計算。
   - 次に試すべき最適なシミュレーション定数（SGSモデル定数や火炎加速力パラメータ）を提案。

3. **`generate_bins.py`**
   - 化学反応解析ソフト `Cantera` を用いて、GRI-Mech3.0メカニズムから必要な化学種の熱力学データおよび輸送係数（粘性係数、熱伝導率、二成分拡散係数）を計算。
   - C言語コードで高速に読み込めるよう、Fortran形式のバイナリデータ（`chem.bin`, `tran.bin`）として出力。

4. **`analysis.py`**
   - LESから出力された数百万行に及ぶプローブデータ（CSV）を解析し、流速の条件付きPDF、レイノルズ応力の分布、Quadrant Analysis（象限解析）、時系列の統計的収束性などのグラフを自動生成します。
   - **パフォーマンスの工夫**: 
     - 大量データの読み込みボトルネックを解消するため、`pyarrow`エンジンによる高速読み込みと`.pkl`（Pickle）によるバイナリキャッシュ機構を実装。
     - 複数の重い描画タスク（KDE計算など）を `concurrent.futures.ProcessPoolExecutor` を用いてマルチプロセスで並列実行し、処理時間を大幅に短縮しています。

## 使用技術・ライブラリ (Tech Stack)
* **C言語**: シミュレーション本体（OpenMPによるスレッド並列化）
* **Python 3**: 最適化および物性値生成スクリプト
  * `numpy`, `pandas`, `scipy`
  * `scikit-learn` (ベイズ最適化 / ガウス過程回帰)
  * `cantera` (熱力学・輸送係数の計算)

## アピールポイント
* **フルスクラッチでの実装**: 既存のソルバーに頼らず、数値計算スキーム（WENO5やRK4等）を自作して実装しています。
* **機械学習の導入**: シミュレーションの定数チューニングという泥臭い作業を、ベイズ最適化を用いて自動化・効率化するパイプラインを構築しました。
* **パフォーマンス最適化**: C言語側のOpenMPによるマルチスレッド化だけでなく、Python側（データ解析）でもマルチプロセス並列化やPickleを用いたキャッシュ機構を実装し、I/Oと計算のボトルネックを解消する実務的な工夫を行っています。
