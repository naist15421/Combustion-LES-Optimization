# 3D LES Combustion Simulation & Parameter Optimization

ES提出用リポジトリです。
燃焼器内の乱流予混合火炎を解析するための3次元LES（Large Eddy Simulation）ソルバーと、その計算パラメータを実験値に適合させるためのベイズ最適化スクリプト群です。

※注意
従来のSGS（サブグリッドスケール）モデルでは予測困難であった「熱膨張に起因する流速の二峰性分布」を再現するため、独自の複合物理モデル（運動量強制項の導入など）を考案し、ソルバーに直接組み込んでいます。

## 概要
本プロジェクトは以下の主要なコード群で構成されています。

1. **`les_combustion_solver.c` (メインソルバー)**
   - 3次元LESによるプロパン(C3H8)-空気予混合火炎の燃焼シミュレーションコード。
   - **新規SGS燃焼モデルの実装**: 実験で観測される流速の二峰性（bi-modal）分布やレイノルズ応力の減衰を再現するため、運動量方程式への明示的なソース項（強制項）の追加や熱力学的ナッジングを組み合わせた、独自の複合物理モデルを導入しています。
   - G方程式（レベルセット法）を用いた火炎面追跡と、WENO5/MUSCLスキーム等の高次精度風上差分を実装。
   - 合成渦法（SEM）による流入乱流の生成、およびOpenMPを用いたスレッド並列計算を実装。

2. **`bayesian_optimizer.py` (パラメータ最適化)**
   - Gaussian Process（ガウス過程回帰）を用いたベイズ最適化スクリプト（`scikit-learn`を使用）。
   - LESコードが出力したレイノルズ応力のプロファイルを読み込み、実験値の近似曲線との誤差（スコア）を計算。
   - 次に試すべき最適なシミュレーション定数（SGSモデル定数や火炎加速力パラメータ）を自動で提案します。

3. **`generate_bins.py` (物性値バイナリ生成)**
   - 化学反応解析ソフト `Cantera` を用いて、GRI-Mech 3.0 メカニズムから必要な化学種（C3H8/CH4, O2, N2, CO2, H2O 等）の熱力学データおよび輸送係数を計算。
   - C言語ソルバー起動時のオーバーヘッドをなくすため、Fortran形式のバイナリデータ（`chem.bin`, `tran.bin`）として事前出力します。

4. **`analysis.py` (計算結果の解析・可視化)**
   - LESから出力された数百万行に及ぶプローブデータ（CSV）を解析し、流速の条件付きPDF、レイノルズ応力の分布、Quadrant Analysis（象限解析）、時系列の統計的収束性などのグラフを自動生成します。
   - **パフォーマンスの工夫**: 大量データのI/Oボトルネックを解消するため、`pyarrow`エンジンと`.pkl`（Pickle）によるバイナリキャッシュ機構を実装。さらに複数の重い描画タスクを `concurrent.futures.ProcessPoolExecutor` を用いてマルチプロセスで並列実行し、処理時間を大幅に短縮しています。

## 使用技術・ライブラリ
* **C言語**: シミュレーション本体（OpenMPによるスレッド並列化）
* **Python 3**: 最適化、物性値生成、データ解析スクリプト
  * `numpy`, `pandas`, `scipy`
  * `scikit-learn` (ベイズ最適化 / ガウス過程回帰)
  * `cantera` (熱力学・輸送係数の計算)
  * `matplotlib`, `seaborn` (データ可視化)

## アピールポイント
* **物理現象に基づいた新規モデルの開発**: 既存のソルバーをただ使うのではなく、実験事実（熱膨張による能動的な流体の加速）のメカニズムを考察し、それを再現するための新しい物理モデルを自ら数式化し、C言語で実装しています。
* **機械学習の導入**: シミュレーションの定数チューニングという泥臭い作業を、ベイズ最適化を用いて自動化・効率化するパイプラインを構築しました。
* **パフォーマンス最適化**: C言語側のOpenMPによるマルチスレッド化だけでなく、Python側（データ解析）でもマルチプロセス並列化やPickleを用いたキャッシュ機構を実装し、研究全体の計算時間・解析時間を短縮する実務的な工夫を行っています。
